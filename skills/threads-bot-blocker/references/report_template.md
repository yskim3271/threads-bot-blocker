# 리포트 형식 (`scripts/render_report.py`, v3.0 시안 B — 요약표 + 증거 댓글, 쉬운 한국어)

**리포트는 스크립트가 만든다. 에이전트는 출력을 다시 쓰거나 요약하거나 표로 바꾸지 않고 그대로 보여 준다.** 덧붙일 수 있는 것은 리포트 **아래** 1~2줄뿐이다(예: "차단할 번호를 알려 주세요").

## 옵션
| 옵션 | 기본 | 설명 |
|---|---|---|
| `--format cli\|markdown` | `cli` | `cli`는 터미널용 텍스트(파이프 표·HTML 없음). `markdown`은 문서·채팅 UI용(5열 표 + `[증거 댓글]`) |
| `--width N` | 100 | CLI 표시 폭(최소 60, 80도 지원). 한글·이모지는 2칸으로 계산하고 모든 줄을 이 폭 안에 맞춘다 |
| `--verbose` | 끔 | 계정별 세부 점수(`세부:`·`합계:`·`지표:`·인용·경고, `합계:`에 `경계(±3점)`·`정성 미적용` 보조 표기), `표본:` 줄, 하단 `[🟢 정상 N명]` 목록(+`고속 단문` 메모) |
| `--out FILE` | – | stdout 출력과 함께 파일로도 저장 |
| `--title TEXT` | – | 헤더의 `Threads 댓글 봇 스캔` 교체 |

## 규칙
- **헤더 1줄**: `Threads 댓글 봇 스캔 (시각 KST)  │  스캔 N명 · 감지 M명`. 감지 = 🔴/🟠 + 🟡 + 🤝. 정성 판정이 빠진 계정이 있을 때만 `※ 정성 미적용(정량 기준) N명` 1줄을 붙인다.
- **정상 문구 없음**: 기본 출력에는 `정상 N명`, `정상 제외`, `--verbose 에서 표시` 같은 안내를 어디에도 쓰지 않는다. `--verbose`에서만 하단에 `[🟢 정상 N명]` 목록과 `고속 단문`(10분 안 짧은 댓글 8개+이지만 즉흥 반응) 메모가 붙는다.
- **감지 0명**이면 요약표·증거 대신 `  감지된 댓글 봇·영업·품앗이 계정이 없습니다.` 1줄만 나온다(차단 가이드도 생략).
- **쉬운 한국어**: 요약표·증거 설명에는 기호(`≤`), 분수(`4/5`), 내부 용어(연사·꼬리·시그니처·바이오·템플릿 등)를 쓰지 않는다. 비율은 `5개 중 4개 같은 댓글`처럼 풀어 쓴다.
- **요약표**: 순수 공백 칼정렬이다(파이프 `|`·HTML 없음). `pad_right`/`pad_left`가 `display_width`(한글·이모지 2칸) 기준으로 맞추므로 `🔴`/`🟠`/`🟡`/`🤝`가 있어도 열이 어긋나지 않는다. 점수는 오른쪽 정렬.
  - 번호는 🔴/🟠 → 🟡 → 🤝 순서이며 차단·뮤트 승인에 쓴다.
  - 판정: 75+ `🔴 차단권장` · 50~74 `🟠 검토필요` · 25~49 `🟡 관찰` · 품앗이(50 미만) `🤝 뮤트권장`.
  - 핵심 사유: +5 이상 강한 신호 최대 3개(모자라면 2개까지 채움). 폭(예: 80)에 안 들어가는 항목은 건너뛰고 다음 짧은 항목을 넣는다.

  | 신호 | 표기 | 신호 | 표기 |
  |---|---|---|---|
  | R1_dup_burst | 20초 내 연속 도배 | R4_shop_link / R4_own_link / R4_link | 쇼핑 링크 / 자사 링크 / 외부 링크 |

  | R2_signature | `{n}개 중 {sn}개 끝에 '{sig}' 반복` | R5_empty / R5_low_follow | 빈 프로필 / 팔로워 30명 미만 |

- **`[증거 댓글]`**: 계정마다 `  n. @handle  (프로필 링크)` 1줄. 경계·정성 미적용 배지는 붙이지 않는다(`--verbose` `합계:` 줄에만 표기).
  - 증거 1건 = 3줄: ① `     • "댓글 원문"`(폭에 맞게 `…`로 자름) ② `       출처 · 쉬운 설명`(대괄호 없음, 길면 7칸 들여쓰기로 줄바꿈) ③ **의심 댓글 직접 링크** `https://www.threads.com/@<handle>/post/<code>`(**URL은 절대 자르지 않는다**).
  - 출처: `@원글작성자 글 댓글`, 본인 글이면 `본인 글 답글`. 설명은 첫 핵심 태그를 풀어 쓴다 — `34초 만에 같은 댓글 4번 반복`(60초 이상은 `2분 31초 만에…`), `남의 글에 쇼핑몰 링크 홍보`, `남의 글에 본인 사이트 링크 홍보`, `남의 글에 외부 링크 삽입`, `댓글에서 프로필·DM·구매 유도`, `사람이 치기 어려운 속도로 긴 댓글 작성`, `15개 중 7개 댓글 끝에 ':)' 표현 반복`, `맞팔·품앗이 유도 댓글`, 🤝는 `16개 중 5개가 맞팔·품앗이 댓글 (차단보다 뮤트 권장)`. 태그가 없으면 AI 판정이 있을 때만 `AI가 쓴 듯한 정형화된 댓글 의심`.
  - 건수: 🔴/🟠 최대 3건(링크·복붙·품앗이·영업 문구 태그 우선, 모자라면 긴 답글로 2건까지), 🟡 최대 2건, 🤝 대표 1건.
  - `• 참고:`는 `human_counter_evidence`에 실질적 반증·판단 보류 맥락이 있을 때만 쓴다. `반증 없음…`처럼 단순 부정이면 생략한다(🤝는 생략).
  - `⚪ 답글 미수집` 계정은 증거 아래 1줄 요약 + `↳ 답글 검증 권장: scripts/bsk_scan.py replies …`.
- **차단 가이드 2줄 고정**: `→ 차단 요청`(명시 승인 시 1개씩, 최대 5개) / `→ 직접 차단`(프로필 링크 → ⋯ → 차단, 확인 없이 절대 차단하지 않음).
- `--format markdown`: 같은 구조 — `| # | 계정 | 점수 | 판정 | 핵심 사유 |` 5열 표, `### [증거 댓글]`, 계정 제목 `**1. [@handle](프로필)**`(배지 없음), 불릿 `- "원문" — [댓글 보기](직접 링크)` 다음 줄에 `  출처 · 쉬운 설명`. 정상 목록은 `--verbose`에서만, `<details>` 없음.
