# 댓글 봇(Reply Bot) 패턴 카탈로그 (v3.0)

`scripts/reply_score.py`가 쓰는 패턴이다. 표본은 **댓글러 1명당 최근 답글 최대 15개**(`/@h/replies`)와 댓글창에서 본 댓글이다. 같은 글(`code`)은 한 번만 센다.

근거는 2026-11-23 실측 23명(홈 피드 인기 글 7개의 댓글러 20명 + 라이브 참조 3명, 답글·댓글 314개)이다. 실측 원문은 저장소에만 있고 배포 스킬에는 없다. 아래 예시는 **익명 별칭과 재구성 문장**이다.

측정: **[정량]** `reply_score.py`가 계산 · **[정성]** LLM이 [llm_rubric.md](llm_rubric.md)로 판정.

## 실측에서 확인한 두 함정 (설계 전제)
1. **고속 단문 인간.** 평범한 사람도 자기 글 댓글이나 친구 글에 10분 안에 10~12개를 단다(`ㅋㅋㅋ`, `토닥토닥`, `그취`, `아인거같은데예`). 23명 중 3명이 `b10`(10분 내 최대 답글 수) 10~12였고 모두 사람이었다. → **단순 답글 수·속도는 점수에 넣지 않는다.** R1은 중장문(≥30자)·복붙·기계 리듬과 결합할 때만 센다.
2. **댓글창 팔로잉 오판.** 댓글창에서는 카드 `textContent`가 `{handle}`로 시작해서 "핸들로 시작하면 팔로잉" 규칙이 123개 중 118개를 팔로잉으로 버렸다. → 댓글창은 **행 단위 팔로우 오버레이**만 본다: 있으면 `false`, 없으면 `"unknown"`, `true`는 만들지 않는다(`bsk_scan.comment_following`).

## R1. 비인간적 답글 속도·리듬 [정량] (상한 25)
| ID | 기준 | 점수 | 근거 |
|---|---|---|---|
| R1_dup_burst | **서로 다른 원글**에 단 연속 답글이 유사도 ≥0.8(8자 이상)이고 간격 ≤20초 | 2회 이상 +25, 1회 +15 | 복붙 품앗이 계정: 34초 안에 3개 글에 같은 문구 4회(간격 7~16초) |
| R1_fast_long | 30자 이상 답글을 앞 답글 뒤 `글자수/4`초 안에 씀(초당 4자 초과 = 붙여넣기·자동 생성) | 2회 이상 +15, 1회 +8 | 실측 사람 0건 |
| R1_long_burst | 10분 창 안에 30자 이상 답글이 서로 다른 대상 4명 이상에게 | 8개+ +20, 6~7개 +12, 5개 +6 | 실측 사람 최대 4개 |
| R1_rhythm | 30초~1시간 간격 5개 이상의 변동계수 ≤0.12 (기계적 등간격) | +12 | 사람 CV 0.43~1.69 |
| (b10) | 10분 내 최대 답글 수 | **점수 없음**(지표만) | 함정 1 |

## R2. 복붙·구조·시그니처 반복 [정량] (상한 25)
| ID | 기준 | 점수 |
|---|---|---|
| R2_dup | 다른 원글 답글과 근사 중복(유사도 ≥0.8)인 답글 비율 | ≥0.5 +20, ≥0.3 +12, 2개 이상 +6 |
| R2_signature | 끝 이모지·이모티콘(`👋😄🧡`의 마지막 문자, `: )` 등)이 같은 비율. `ㅋㅋ·!!·^^`처럼 흔한 꼬리는 제외 | ≥0.5(4회+) +10, ≥0.35(4회+) +6. **답글 75% 이상이 내 글 댓글(호스트 답글)이면 절반** |
| R2_template | 답글 쌍 평균 유사도 ≥0.45 (4개 이상) | +8 |
| R2_question | 질문형 마무리 ≥0.6 + 평균 30자 이상 (5개 이상) — "공감 + 질문" 틀 | +6 |

## R3. AI 답글 슬롭 [정성] (상한 25)
- 0 / 1(**+12**: 다듬은 공식 공감·브랜드 톤) / 2(**+25**: 원글 키워드 앵무새 재진술 + 과잉 친절 + 인위적 질문 + 실제 오타 0이 답글 대부분에서 반복).
- 인용 필수. 인용이 수집 원문에 없으면 0점(지어낸 인용 차단).

## R4. 기생 영업·제휴·품앗이 [정량] (상한 25, **내 글 댓글은 제외**)
| ID | 기준 | 점수 |
|---|---|---|
| R4_shop_link | 타인 글 댓글에 쇼핑·제휴 URL(`shopping.naver`, `smartstore.naver`, `coupang`, `11st`, `gmarket`, `aliexpress`, `temu`, `?ref=`·`utm_`·`payback` 등) | +20 |
| R4_own_link | 타인 글 댓글에 자사·본인 도메인(도메인 첫 마디가 핸들과 겹치거나 바이오 링크 도메인과 같음) | 2개+ +18, 1개 +15 |
| R4_link | 그 밖의 외부 링크 | 2개+ +8, 1개 +3 |
| R4_promo | 프로필·DM 유도, "검색하면", 할인 코드·쿠폰·공구·체험단·무료 상담 등 | 2회+ +6, 1회 +3 |
| R4_pumasi | `스하리·반하리·맞팔·선팔·품앗이·좋반·팔로우 완료·소통해요` 답글 비율 | ≥0.5 +15, ≥0.25 +10, 2회+ +6, 1회 +2 |

## R5. 프로필 신호 [정량] (상한 15, 프로필 미수집이면 0)
| ID | 기준 | 점수 |
|---|---|---|
| R5_kw | 이름·바이오에 자동화·봇 키워드(`P5_KW`, 아래 부록) — LLM `P5_exempt`면 0 | +10 |
| R5_bio_pumasi | 바이오에 품앗이 문구(`스하리=반하리`, `맞팔`) | +4 |
| R5_bio_shop | 바이오 링크가 쇼핑·제휴·리퍼럴 | +4 |
| R5_empty | 바이오 없음 + (이름 없음 또는 팔로워 <50) | +4 |
| R5_low_follow | 팔로워 <30 | +2 |
| R5_reply_only | 본인 글 0개 + 답글 5개 이상 | +5 |

## RH. 인간 반증 (감점, 하한 −25)
| ID | 측정 | 기준 | 점수 |
|---|---|---|---|
| RH1 | 정성 | 실제 오타·비표준 구어·사투리(`욜심히`, `가야게따`, `시정하겟읍니다`, `거덩예`) | −8 |
| RH2 | 정성 | 원글 맥락에 딱 맞는 구체적 경험·고유명사·실제 대화(1 = 일부, 2 = 대부분) | −6 / −12 |
| RH3_short | 정량 | 품앗이 답글을 뺀 표본에서 12자 이하 비율 ≥0.4 & 길이 CV ≥0.5 → −8, ≥0.25 & CV ≥0.5 → −4 | |
| RH3_colloquial | 정량 | `ㅋㅋ·ㅎㅎ·ㅠ·자모·;;` 구어 비율 ≥0.3 | −5 |
- RH3는 **복붙·템플릿 증거(R2 ≥10 또는 중복 ≥0.3)가 있으면 적용하지 않는다** — 복붙 단문은 사람 증거가 아니다.
