# 댓글 봇 점수 체계 (v4.0) — `scripts/reply_score.py`와 동기화된 단일 기준

## v4.0 구조: 증거 기반 LLM 우선 하이브리드
```
수집(답글 15개 + 프로필·최근 원글) → ① 증거 패킷(--emit-packets, 점수 없음)
  → ② LLM 종합 판정(llm_rubric.md: category · score 0~100 · summary_reasons · evidence[code+quote+why])
  → ③ VG1 원문 인용 검증 → VG4 → VG5 → VG3 → VG2 → 등급 → 경계(±3) → 리포트
       판정 없음 · v3.0 형식 · 검증 인용 0건 → 아래 정량 엔진(v3.0 호환)으로 채점
```
| 단계 | 담당 | 내용 |
|---|---|---|
| 증거 패킷 | 스크립트(조사관) | 프로필(이름·바이오·팔로워·바이오 링크·**최근 원글 3개 + 고정·이전 글 1개**), 시간순 답글(`gap_prev_sec`·`len`·`reply_to`·`parent_excerpt`·태그·`batch`), `burst_batches`, `repeat_10m_pairs`, `daily_schedule_hint`, 중복·도메인·개수, `triage`(review / low_priority). **점수·등급·판정 필드는 없다** |
| 종합 판정 | LLM(판사) | 패킷 전원을 읽고 예약·배치 리듬, 바이오·원글·답글의 자기 고백, 프로필↔답글 모순, AI 공감 문체, 복붙, 기생 영업 vs 단발 언급, 품앗이를 함께 본다 |
| 검증·채점 | 스크립트(검증관) | 인용 대조와 하드 팩트 가드레일만 적용한다. LLM 점수를 근거 없이 바꾸지 않는다 |

### 가드레일 (`VG1~VG5`, `judgment_mode: llm_v4`)
| ID | 조건 | 결과 |
|---|---|---|
| VG1 인용 검증 | `evidence[].quote`(앞뒤 `…` 제거, 공백 무시, 4자 이상)가 답글·바이오·이름·최근 원글에 그대로 있어야 한다 | 없으면 그 근거만 제외 + 경고 `인용이 수집 원문에 없음 → 제외`. 검증 인용 0건인데 `score ≥ 25`이거나 범주가 `ai_bot`·`copy_spam`·`sales_spam`이면 `검증된 원문 인용 0건 → 정량 기준 폴백`(`judgment_mode: quant_fallback`) |
| VG2 표본 부족 | 답글 4개 미만인데 75 이상 | 74 |
| VG3 하드 팩트 하한 | 20초 안 복붙 2회+(`dup_burst ≥ 2`) / 쇼핑 링크 1회+ / 남의 글 자사 링크 2회+ | 75 / 50 / 50. **자사 링크 1회는 하한 없음**(사람의 단발 언급은 LLM이 판단) |
| VG4 품앗이 분리 | `category: pumasi`(쇼핑 링크·복붙 도배·자사 링크 2회+ 없음) | 49 상한, 🤝 뮤트권장 섹션. 정량 🤝 배지가 있고 50 미만이며 `human`이 아니어도 🤝 섹션 |
| VG5 사람 보호 | `category: human`인데 25 이상, VG3 조건 없음 | 24 |
- 결과에는 기존 필드(`total`·`tier`·`categories`·`items`·`gates`·`labels`·`samples`·`metrics` …)가 모두 남고, `judgment_mode`·`category`·`llm_score`·`quant_total`(정량 참고값)·`summary_reasons`·`verified_evidence`(`source_type` reply / root_post / bio, `url`, `reply_to`, `text`, `quote`, `why`)가 더해진다.
- 판정 방식은 계정마다 자동으로 정한다: `score`/`category`가 있으면 `llm_v4`, `R3`/`RH1`/`RH2`만 있으면 `llm_v3`, 판정이 없으면 `quant_only`.

## 정량 엔진 (v3.0 호환 · 폴백)
```
댓글 봇 점수 = clip₀..₁₀₀( R1[≤25] + R2[≤25] + R3[≤25, 정성] + R4[≤25] + R5[≤15] + RH[≥−25] )
            → RG1 → RG2 → RG3 → RG4 → RG5 → 등급 → 경계(±3) → 🤝 품앗이 / 💸 영업 링크 배지
```
표본: 댓글러 1명당 `/@h/replies` 최근 15개 + 댓글창 댓글(같은 `code` 1회). 세부 기준과 정규식은 [patterns.md](patterns.md).

| 축 | 내용 | 핵심 기준 |
|---|---|---|
| **R1** 속도·리듬 | 단문 연사는 **세지 않는다**(고속 단문 인간 함정) | 서로 다른 원글 ≤20초 복붙 2회+ +25 · 초당 4자 초과 중장문 · 10분 내 30자+ 답글 5/6/8개(대상 4명+) · 기계 등간격(CV ≤0.12) **또는** 3분 안 배치 4개+ · 30자+ 4개+ · 간격 CV ≤0.20 → +12 |
| **R2** 복붙·구조 | 근사 중복 비율, 시그니처 꼬리, 평균 유사도, 질문형 틀 | 중복 ≥0.5 +20 · 시그니처 ≥0.5 +10(호스트 답글이면 절반) · 평균 유사도 ≥0.45 +8 · 질문형 ≥0.6 +6 |
| **R3** AI 답글 슬롭 | 정성(LLM, 인용 필수·원문 대조) | 0 / +12 / +25 |
| **R4** 기생 영업·품앗이 | 타인 글 댓글만 | 쇼핑·제휴 링크 +20 · 자사 링크 +15/+18 · 기타 링크 · 영업 문구 · 품앗이 비율 ≥0.5 +15 / ≥0.25 +10 |
| **R5** 프로필 | 프로필 미수집이면 0 | 자동화 키워드 +10(`P5_exempt` 감면) · 품앗이 바이오 +4 · 쇼핑 바이오 +4 · 빈 프로필 +4 · 팔로워<30 +2 · 본문 0 +5 |
| **RH** 인간 반증 | 정성 RH1·RH2 + 정량 RH3 | RH1 −8 · RH2 −6/−12 · 단문·길이 다양성 −4/−8 · 구어체 −5 (복붙·템플릿 증거가 있으면 RH3 미적용) |

## 등급·배지·신뢰도
| 점수 | 등급 | 신뢰도(답글 수) |
|---|---|---|
| 75–100 | 🔴 댓글 봇 차단권장 | ●●● 높음 ≥10 |
| 50–74 | 🟠 댓글 봇·영업 의심 | ●●○ 보통 ≥4 |
| 25–49 | 🟡 관찰 | ●○○ 낮음 <4 |
| 0–24 | 🟢 정상 | ⚪ 답글 0개 = 답글 미수집 |
- **🤝 품앗이 답글러**: 품앗이 답글 비율 ≥0.25, 또는 품앗이 바이오 + 2회 이상. 50점 미만이고 영업 링크가 없으면 리포트의 🤝 섹션(뮤트 권장)에 들어간다. **💸 영업 링크 답글**: R4_shop_link/R4_own_link.
- **⚠️경계**: 25·50·75에서 ±3점 이내.
- **`needs_llm`**(사전 필터 · 증거 패킷의 `triage: review`): R1+R2+R4+R5 ≥8, 링크·영업 문구·품앗이 1회 이상, 10분 내 장문 3개 이상, 초고속 장문, 근사 중복 2개 이상, 자동화 키워드, 30자 이상 답글 5개 이상 중 하나. 짧은 즉흥 댓글만 단 사람은 v3.0 흐름에서 LLM을 건너뛴다(`정성 생략(사전 필터 미달)`). v4.0 증거 패킷에는 `triage: low_priority`로 함께 들어간다.
- **Graceful degradation**: 정성 판정 파일이 없거나 깨졌거나 일부 계정만 있어도 끝까지 채점한다. 빠진 `needs_llm` 계정은 `정성 미적용(정량 기준)`(R3·RH1·RH2 = 0). 해석 불가 값·인용 없음·원문에 없는 인용은 0점 + `warnings`.
- **의심 댓글 직접 링크**: `samples[].url` = `https://www.threads.com/@<handle>/post/<code>`(수집 항목에 URL이 없으면 `code`로 만든다). 리포트 예시마다 출력된다.
